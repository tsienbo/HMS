## 排查：.wrapper 的 max-width "没生效"

- 结论：CSS 本身正确。`.wrapper { max-width: 1240px; margin: 0 auto }` 已生效，用无头 Edge 在 1600px 视口实测左右各留白 180px = (1600-1240)/2。
- 真实原因：窗口宽度 ≤ 1240px 时，max-width 作为「上限」不产生可见效果；且 `.topbar` 的背景/下边框是全宽的（正常现象），容易被误判为没生效。
- 建议并已采纳：给全局 `*` 加 `box-sizing: border-box`，让 max-width 把 padding/border 算进去（原 `.container` / `.wrapper` 的 24px padding 会让实际占位变成 1288px）。

## 环境备忘（Windows 无头截图）

- Edge 路径：`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`
- 可用配方：`--headless=old --disable-gpu --user-data-dir=<全新临时目录> --screenshot=<反斜杠绝对路径> --window-size=W,H`
- 坑：同一条命令里连续调两次通常只有第一次成功；每次都要换新的 user-data-dir；个别宽度会静默失败，重试或换宽度即可。
- 注意：不要用 `taskkill /IM msedge.exe`，会误关用户正在用的浏览器窗口。
